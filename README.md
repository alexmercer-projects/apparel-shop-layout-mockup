# Small-batch apparel shop layout mockup

A layout mockup for a small-batch apparel shop: logo and wordmark placeholders, a filterable product grid, a simple product dialog with sizes and a buy button, and an about block.

This is a concept demo. There is no real brand, inventory, or sales history. The name, pieces, prices, colors, and photos are placeholders.

## View it

Live demo: https://alexmercer-projects.github.io/apparel-shop-layout-mockup/

Or open `docs/index.html` in a browser. There is no build step. The buy button does not check out.

## Tech

A single HTML file with the CSS and a little JavaScript inline.
